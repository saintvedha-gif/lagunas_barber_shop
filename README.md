# Laguna's Barber & Shop 💈🛍️

API REST completa para una barbería con tienda integrada.
Migración de un sistema legacy en PHP/MySQL a Node.js, TypeScript y MongoDB Atlas.

## 🛠 Tecnologías
- **Backend:** Node.js, Express, TypeScript
- **Base de datos:** MongoDB Atlas + Mongoose
- **Auth:** JWT
- **Imágenes:** Multer (migrando a Cloudinary)
- **Deploy:** Railway / Render (próximamente)

## 📌 Funcionalidades
- Autenticación con JWT
- CRUD de productos, categorías y servicios de barbería
- Gestión de órdenes
- Panel admin (en desarrollo)
- Subida de imágenes

## 🚀 Correr el proyecto
```bash
cd backend
npm install
npm run dev
```
